# Architecture decision records

Each record states one decision, the context it was made in, the options that were weighed and the consequences.
A record is never rewritten after it is accepted; a later record supersedes it.

Status values: **Proposed** (under review in a pull request), **Accepted**, **Superseded by ADR-nnnn**.

| [0007](0007-mcp-client.md) | MCP client for external tools | Accepted |
